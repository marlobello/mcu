# Web client

The MCU web client is a React 19 and TypeScript single-page application built with Vite.

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```

Set `VITE_API_URL` to the Functions API base URL. It defaults to `http://localhost:7071/api`.

The production build is written to `dist` and deployed to Azure Static Web Apps.
